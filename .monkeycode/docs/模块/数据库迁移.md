# 数据库迁移模块

`real_sync/database/migrations/` 保存版本化增量 SQL。迁移用于把数据库结构演进从请求期间 DDL 逐步收口为可追踪、可核验的版本。

## 迁移运行器

`real_sync/database/MigrationRunner.php` 按文件名顺序读取迁移，并在 `schema_migrations` 中记录版本、文件名、SHA-256 校验值、状态和执行时间。结构核验清单位于 `real_sync/database/migration_manifest.php`。

```bash
php scripts/migrate.php status
php scripts/migrate.php apply --dry-run
php scripts/migrate.php apply
php scripts/migrate.php verify
php scripts/migrate.php rollback-plan
```

执行结果包含结构差异、表行数差异和核验错误。保留式回滚计划切回旧应用读取路径并保留增量表和字段。

## 员工组织迁移行为

- 条件增加 `staffs` 和 `stores` 字段。
- 条件增加员工工号、用户 ID 和门店编码唯一索引。
- 创建五张员工组织治理表。
- 预置销售、教练、店长、总部运营、财务、负责人和系统管理员岗位。
- 将历史 `job_title` 映射为稳定岗位记录。
- 回填 `staffs.primary_position_id`。
- 为现有员工生成首条主任职记录。
- 保留现有业务表和历史记录。

## 工作量治理迁移行为

- 创建九张工作量治理表，保留现有日报、指标值、凭证和审核任务。
- 为日报绑定初始统计口径版本和岗位规则版本。
- 扩展模板最低正数项目数与生效区间，初始规则保持四个正数项目。
- 将 `h5`、`mini_program` 初始化为生产来源，将联调、调试和测试来源初始化为合成来源。
- 只从已有历史日报回填义务，周一记录标记为公休日豁免。
- 为日报来源统计、员工来源统计、版本查询、指标聚合和审核积压补充条件索引。
- 预置草稿、锁定缺交、门店完成率和审核积压规则。

## 工号序列迁移行为

- 创建 `staff_employee_number_sequences`，以工号前缀作为主键。
- 员工创建事务通过 `SELECT ... FOR UPDATE` 锁定当前序列。
- 序列分配会跳过历史员工已占用的工号。
- 迁移仅增加新表并保留现有员工数据。

## 审核历史迁移行为

- 保留现有审核任务，并将其视为版本 1。
- 增加 `task_version`、`previous_task_id` 和 `superseded_at`。
- 为日报项目审核历史、前序版本和当前积压建立索引。
- 重新提交时由应用服务废止当前任务并创建递增版本的新任务。

## 审核重审迁移行为

- 为审核任务增加 `evidence_count_at_review`。
- 后台要求补凭证时保存当前凭证数量。
- 员工重新送审时要求当前凭证数量高于该基线。
- 历史任务保留空基线，并由应用服务按审核时间兼容判断。

## 新增迁移

1. 使用递增版本号创建新 SQL 文件。
2. 先核对线上结构和历史数据冲突。
3. 采用增量语句与确定性数据回填。
4. 添加契约和数据库集成测试。
5. 在隔离历史库副本执行并核对计数。
6. 生产执行前建立表结构和数据备份。
