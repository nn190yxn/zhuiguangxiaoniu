## 平台同步迁移行为

- `platform_sync_drafts` 按员工、业务域、对象类型和对象 ID 建立唯一草稿，保存草稿版本、业务基础版本、来源客户端、设备和有效期。
- `platform_sync_changes` 保存授权范围摘要、稳定对象、状态版本、A/B/C 等级、活动或墓碑状态、ETag 和发生时间。
- 增量索引按授权范围、发生时间和自增 ID 排序，保证游标分页稳定。
- 对象、草稿和变更数据采用新增表承载，保留既有业务表与历史契约。

## 迁移运行器

`real_sync/database/MigrationRunner.php` 按文件名顺序读取迁移，并在 `schema_migrations` 中记录版本、文件名、SHA-256 校验值、状态和执行时间。`real_sync/database/migration_catalog.php` 以 Adapter 方式复用冻结清单，为 42 个迁移补充固定 checksum、结构预期、数据核对模式和已验证兼容声明。运行器会同时校验 SQL 内容和 catalog 文件数量。

```bash
php scripts/migrate.php status
php scripts/migrate.php compatibility
php scripts/migrate.php readiness
php scripts/migrate.php apply --dry-run
php scripts/migrate.php apply
php scripts/migrate.php verify
php scripts/migrate.php rollback-plan
```

执行结果包含兼容、结构、表行数和核验错误。`ExpandMigrateContractValidator` 静态阻断字段删除与重命名，校验新增字段的默认值、可空语义或 N/N-1 写入适配器，并要求新状态语义具备确定性降级映射和兼容窗口功能开关。`compatibility` 可单独输出机器可读证据，`apply` 和 `readiness` 均强制执行该门禁。`readiness` 随后以纯 SELECT 核对迁移历史、目标表、列、索引和 checksum，结构通过后执行数据转换迁移声明的 `expected_zero` 查询；纯新增结构迁移使用 `structural_only` 模式。任一差异阻止批次。保留式回滚计划切回旧应用读取路径并保留增量表和字段。

API Kernel 提供 `platformRequireMigrationReadiness()`。请求期只检查端点依赖的目标版本，不运行 DDL、迁移应用或业务表全量计数。会话刷新、小程序设备会话、同步、Admin 身份审计、企微、提醒、技能、周年活动和暑期评估入口已接入，统一任务入口额外检查平台任务、outbox 和任务载荷摘要结构；HTTP 入口在结构未就绪时返回稳定 `503/schema_not_ready`，CLI Worker 以非零状态退出。

## 迁移重放与核对

`real_sync/database/MigrationReplayVerifier.php` 从明确时间窗内采集只读证据，业务变更来源为 `platform_sync_changes`，并在对应表存在时接入 `platform_outbox_events` 和 `platform_side_effect_receipts`。核对项覆盖证据源缺失或截断、业务变更冲突、缺失或孤立 outbox、事件哈希冲突、缺失或孤立副作用、外部结果哈希和幂等键冲突。

```bash
php scripts/migration-replay.php dry-run --since="2026-07-31 09:00:00" --until="2026-07-31 10:00:00"
php scripts/migration-replay.php verify --since="2026-07-31 09:00:00" --limit=10000
php scripts/migration-replay.php rollback-plan --stdin < replay-evidence.json
```

输出使用 `migration-replay-evidence/v1`，以规范化证据计算稳定 SHA-256 `evidence_id`，并提供阻断问题与 `rebuild_outbox_event`、`replay_outbox_event`、`replay_side_effect`、`reconcile_side_effect` 建议动作。工具始终保持 `mutations_applied=false`。保留式计划依次冻结新写入、恢复 N-1 应用、重放业务写入和 outbox、核对外部副作用，并以零阻断差异作为关闭条件。
