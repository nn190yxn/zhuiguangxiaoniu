# 招聘简历导出

## 位置

- 服务：`real_sync/api/admin/recruitment/services/RecruitmentExportService.php`
- 接口：`real_sync/api/admin/recruitment/export.php`
- 后台页面：`real_sync/admin/recruitment-resumes.html`
- 回归测试：`real_sync/scripts/recruitment_resume_export.test.mjs`

## 当前导出数据层

招聘导出服务沿用现有招聘权限、批次、等级和日期筛选。导出数据来源包含已归类的 A/B/C 候选人、待确认岗位文档，以及状态为 `failed` 且分类状态为 `failed` 的简历文档。

每条导出记录携带源简历文档 ID、简历收到日期、收到时间、岗位配置顺序和处理状态。岗位配置顺序来自 `organization_positions.sort_order`；排序值相同时使用招聘需求 ID、收到时间和文档 ID建立稳定顺序。导出数据按源简历文档 ID去重。

## 工作表结构

导出工作簿包含总览、按 `YYYY-MM-DD` 命名的日期工作表、岗位兼容性工作表和未归类确认工作表。日期工作表使用统一字段，并在现有 27 列后增加“处理状态”列，用于区分已归类、待确认岗位和处理失败记录。

日期工作表按日期升序排列；同一日期内按岗位配置顺序、岗位 ID、简历收到时间和源文档 ID排序。总览工作表包含日期范围内的全量源简历记录。
