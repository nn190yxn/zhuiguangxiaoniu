# 受控文件服务

`real_sync/api/platform/FileAssetService.php` 定义平台文件元数据、分类、ACL 和访问审计契约；`real_sync/api/platform/PrivateFileStorage.php` 提供本地私有存储、上传验证、流式读取和留存清理。Drill 音频、工作量导出和招聘简历分别通过领域 Adapter 接入平台文件策略。

## 分类策略

| 分类 | 访问模式 | 存储驱动 | 大小上限 | 生命周期 |
| --- | --- | --- | --- | --- |
| `public_static` | `public` | `web_static`、`object_public` | 100MB | 留存与下载期限可选 |
| `controlled` | `authorized` | `local_private`、`object_private` | 100MB | 必须设置未来留存期限 |
| `temporary_export` | `owner_scoped` | `local_private`、`object_private` | 500MB | 必须设置未来留存和下载期限，下载期限不得晚于留存期限 |
| `sensitive_source` | `authorized_audited` | `local_private`、`object_private` | 100MB | 必须设置未来留存期限 |

所有资产保存用途、所有者、可选业务对象、原始名称、实际 MIME、大小、SHA-256、唯一存储位置、留存策略、状态、创建主体和时间。`storage_key` 是相对键，服务拒绝绝对路径、父目录跳转、反斜杠和控制字符；`original_name` 只接受不含路径的文件名。

## ACL 与判定

`PlatformFileAssetService::grant()` 创建与资产 ID 绑定的主体授权。权限为 `read`、`download` 或 `manage`，可选范围由 `scope_type` 和 `scope_id` 成对表达；授权同时保存业务原因、有效期、撤销时间和授权主体。

`authorize()` 依次检查资产 ID、活动状态、留存期限、下载期限、公开分类、所有者和 ACL。ACL 必须绑定当前资产和当前主体，`manage` 可覆盖具体动作，范围授权必须出现在主体的 `type:id` 范围集合中，过期或撤销授权不产生访问权。返回值包含布尔结果、稳定原因码、命中权限和范围。

每次允许与拒绝判定都写入 `platform_file_access_events`。事件保存资产、操作者、动作、命中权限、判定、原因码、范围、请求 ID、可选访问原因和时间；事件不保存物理存储键或文件内容。

## 私有存储

`PlatformPrivateFileStorage::storeUploadedFile()` 校验 PHP 上传状态和临时文件身份，再委托 `storeFile()`。物理写入前使用 Fileinfo 检测实际 MIME，并核对声明 MIME、白名单、大小上限、实际 SHA-256 和可选预期摘要。存储键使用 `namespace/YYYY/MM/<192-bit-random>.<ext>`，默认根目录为站点 `.private/platform-files/`，也可通过 `PLATFORM_PRIVATE_FILE_ROOT` 配置；目录和文件权限分别为 `0700` 与 `0600`。

`resolveForRead()` 拒绝绝对路径、空键、反斜杠、重复分隔符、`.`、`..` 和控制字符，并在 `realpath` 后确认文件仍位于私有根目录。`prepareDownload()` 支持一个或多个相对键，`stream()` 按顺序输出并设置私有禁缓存、实际长度、安全文件名和 `X-Content-Type-Options: nosniff`。内部绝对路径仅存在于流式计划中，不进入业务响应。

`cleanupExpired()` 只处理活动且留存时间已到的对象，逐项返回 `deleted` 或 `missing`；`missing` 允许 Worker 安全重试。物理删除完成后，业务 Adapter 负责更新领域状态并保留必要元数据和审计事实。

## Drill Adapter

`DrillMediaStorageAdapter` 将资产标记和分片写入 `DRILL_MEDIA_STORAGE_ROOT` 或站点 `.private/drill-media/`。`DrillMediaService::accessAudioAsset()` 返回 `/api/drill/v2/audio-access.php?...&download=1` 受控 URL并排除 `storage_path`；流式请求再次校验当前身份、音频对象、所有者或角色范围、真实录音授权和留存期限，记录允许或拒绝审计后拼接分片输出。

`DrillGovernanceService` 调用同一媒体服务处理到期资源。治理 Worker 清理资产标记与全部分片，摘要只保存存储键哈希和删除结果，资源元数据、评分、复核及认证事实继续保留。

## 工作量 Adapter

`WorkloadPlatformFileAdapter` 校验导出任务已完成、`expires_at` 有效、物理文件存在且 `realpath` 位于批准目录。新任务写入 `PLATFORM_PRIVATE_FILE_ROOT/workload-exports`，默认位置为站点 `.private/platform-files/workload-exports/`；历史 `data/workload-exports/` 继续作为受控兼容目录。`WorkloadExportJobService` 在生成和下载阶段继续执行任务所有者与权限范围摘要重校验，Adapter 只承担临时导出策略、生命周期和路径边界。

## 招聘 Adapter

`RecruitmentPlatformFileAdapter` 将新上传简历写入 `recruitment/resumes` 私有命名空间，并登记为 `sensitive_source` 资产，绑定招聘批次、上传员工和 365 天留存策略。原件预览先校验招聘数据范围和 `recruitment.resume_original_view`，再调用平台资产授权并记录访问事件；缺少 `platform_asset_id` 的历史记录只通过配置的招聘私有根读取。

## 数据结构

- `platform_file_assets`：文件身份、分类、用途、所有权、内容摘要、存储位置和生命周期。
- `platform_file_access_grants`：主体权限、可选业务范围、有效期、撤销和授权审计。
- `platform_file_access_events`：允许与拒绝访问的不可变审计证据。

结构由 `real_sync/database/migrations/202607310013_platform_file_assets.sql` 创建，并在 `real_sync/database/migration_catalog.php` 中登记固定 SHA-256、表列索引和三项只读数据核对。
