# 微信小程序模块

`real_sync/mini-program/` 是当前功能较完整的原生微信小程序工程，覆盖登录、学习、考试、制度、知识库、AI 演练、通关、通知、工作量、绑定、提醒和个人中心。

## 关键文件

| 文件或目录 | 职责 |
| --- | --- |
| `mini-program/app.json` | 页面路由和全局窗口配置 |
| `mini-program/app.js` | 应用生命周期与全局状态 |
| `mini-program/utils/api.js` | API 请求、Token、401 和上传处理 |
| `mini-program/utils/auth.js` | 本地认证状态兼容 |
| `mini-program/pages/` | 页面实现 |
| `mini-program/pages/workload/` | 工作量填报 |

## 请求模式

页面通过 `utils/api.js` 调用 `/api` 接口。请求层附加 Bearer Token，处理 Token 失效和登录跳转，并为文件上传提供统一入口。

## 开发检查

1. 新页面同步注册到 `app.json`。
2. API 请求复用统一请求层。
3. 登录态兼容 `token` 与 `jwt_token` 历史键。
4. 上传、超时和业务错误提供可重试反馈。
5. 在微信开发者工具和真机分别验证。
6. 提审前核对 request、uploadFile、downloadFile 和 web-view 域名。

仓库中的 `real_sync/mobile/` 包含另一套历史移动端及小程序相关源码。发布改动前依据实际微信工程确认目标目录。
