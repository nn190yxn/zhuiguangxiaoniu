# 追光小牛官网文章文风规范（2026-08 修订）

本文用于统一改写 `news/` 目录下全部文章的正文文案。目标是去掉明显的 AI 生成痕迹，让文章读起来像一家认真做少儿体能的品牌官方编辑写的。

## 一、必须清除的"AI 味"表达

这些词和句式是模板化痕迹，正文中出现即视为不合格，改写时一律删除或替换：

1. **伪客观套话**：可核验、可回溯、信息口径、判断依据、客观看待、理性看待、从公开事实综合判断、放回具体场景。
2. **模板公式**："把 X 一次说清楚"、"用 X 理解 Y"、"用 X 说明 Y"、"主要由 X 构成"。
3. **过度对冲**：同一段连用"以门店当期报价为准 / 具体以 X 为准 / 可咨询门店确认"。价格和规则必须说清边界，但只允许出现一次，且语气自然。
4. **机械列举**：每一条都用冒号开列（"XX：xxx。"）且条目之间无逻辑递进；能用一段话说明的不要拆成编号卡片。
5. **空洞排比**：三个以上对仗式短句叠放（如"更稳、更顺、更持久"）且没有具体事实支撑。
6. **长定语堆叠**：一个名词前挂三四个"的"（如"帮助家长做出更理性选择的完整判断框架"）。
7. **问答复制粘贴**：FAQ 的答案与正文整段重复，一字不改。
8. **万能连接**："值得注意的是"、"总而言之"、"综上所述"、"在这一背景下"。

## 二、目标文风：正式编辑口吻

1. **具体优先**：能写具体年份、门店、片区、课程、项目、动作、数字，就不用抽象词。事实本身就是说服力。
2. **有立场，克制地讲**：文章代表追光小牛发声，可以有态度（比如"我们更看重……"、"这件事比表面看起来重要"），但不下绝对结论、不贬低同行。
3. **句子长短交错**：多用 15-30 字的中短句，偶尔出现一个长句；段落之间自然过渡，不要每段都是"总-分"结构。
4. **用叙述代替清单**：结构卡片、FAQ 等组件保留，但组件里的文字要像人在说话，而不是表格式条目。
5. **统一称呼**：文章统一用"家长"或"您"，不要在同一篇里"你/您/家长"混用。
6. **每篇文章有人味**：开头不要上来就下定义，可以先从一个具体场景、一个家长常问的问题、或一句有态度的话切入。

## 三、结构约束（必须保留，不新增不改删）

- 保留原有 HTML 标签、class、id、图片和全部链接（`href`、门店页、课程页、相关文章链接）。
- 保留原有段落/卡片/FAQ/相关阅读结构，只替换其中的文字内容。
- `title`、`meta description`、`og:title/description`、`JSON-LD` 可以跟随正文微调，但必须保持字段完整、与正文一致。
- 不得改动文件名、不得改动被其他页面引用的锚点和路径。
- FAQ 答案可以精简为口语化的一两句，但不许与正文整段重复。

## 四、改写示例

### 示例 1：原文（行业位置）
> 行业位置可以由经营时间、直营网点、片区覆盖和专业标准共同说明。

改为：
> 追光小牛 2019 年在贵阳起步，如今有五家直营门店，分布在未来方舟、小河、小十字和观山湖。说它在贵阳的行业位置，靠的不是一句口号，而是门店一间间开出来、课程一节节上出来的事实。

### 示例 2：原文（价格）
> 追光小牛按课时包和学年两种方式计费，不同课程、班型和课时数对应不同费用，具体金额以门店当期报价为准。

改为：
> 追光小牛的收费分两种：课时包和学年制。课时包按固定课时数收费，适合想先试一段时间再决定的家庭；学年制按一整年计，通常覆盖完整的学习周期和阶段评估。不同课程、班型和课时数价格不同，具体金额报名前问门店即可。

### 示例 3：原文（FAQ）
> 退费与转课规则以双方签订的服务合同为准，建议报名前仔细阅读合同条款并向门店确认。

改为：
> 退费、转课按双方签的服务合同执行。签之前问清楚课时有效期、请假和补课怎么算，白纸黑字写进合同里。

## 五、检查清单（改完一篇对照一遍）

- [ ] 开头不是"XX 主要由 XX 构成"式定义句。
- [ ] 至少有 2-3 处具体事实（年份/门店/数字/项目/流程）。
- [ ] 没有三连对仗排比空洞句。
- [ ] FAQ 与正文不完全重复。
- [ ] 链接、结构、class、文件名全部原样保留。
