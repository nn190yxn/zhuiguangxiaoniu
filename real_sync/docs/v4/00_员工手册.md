## 一、公司概况

追光小牛成立于2019年，专注3-14岁儿童体适能训练，目前在营5家校区。

- **使命**：让每个孩子爱上运动，在运动中成长
- **核心价值观**：专业、真诚、负责、成长
- **品牌slogan**：追光小牛，运动成就未来

## 三、人事制度

### 3.1 试用期与试岗期

| 岗位 | 试用期 | 试岗期 |
|------|--------|--------|
| 教练 | 1-3个月 | 前3天试岗+3天跟岗 |
| 课程顾问 | 1-3个月 | 前3天试岗+3天跟岗 |
| 店长 | 3个月 | 60天带教计划 |
| 教学主管 | 1-3个月 | 前3天试岗+3天跟岗 |
| 销售主管 | 1-3个月 | 前3天试岗+3天跟岗 |

试用期不合格者终止试用。

### 3.2 转正标准

**教练转正**需同时满足以下三个维度：

| 维度 | 标准 | 数据来源 |
|------|------|----------|
| 有效会员数 | ≥40人/月 | GYMGO系统 |
| 月均耗课 | ≥100人次/月 | GYMGO系统 |
| 出勤系数 | ≥0.70 | 排课到课率×50%+人均耗课达成率×50% |

**顾问转正**：试岗期满+试用期考核通过（试讲评分≥B级、家长零投诉、出勤率100%），填写《岗位说明书签署确认表》，正式转正。

### 3.3 离职

| 类型 | 流程 | 要求 |
|------|------|------|
| 主动离职 | 提前30天书面申请→店长审批→总经理审批 | 完成工作交接 |
| 被动离职 | 店长发起→总经理审批 | 按劳动法执行 |
| 试用期离职 | 提前3天通知 | 完成简单交接 |
| 自动离职 | 连续旷工3天或累计旷工5天 | 视为严重违反规章制度，公司有权解除劳动合同 |

**离职交接**须完成：工作交接→客户资料移交→工装工牌归还→GYMGO账号关闭→借款欠款结清→签署离职确认书。

**离职薪资结算**：

| 情况 | 薪资结算 |
|------|----------|
| 正常辞职（提前通知） | 结算至最后工作日，含当月已产生课时费/提成 |
| 即时辞职（未提前通知） | 结算至最后工作日，公司有权要求赔偿因未提前通知造成的损失 |
| 辞退（公司原因） | 结算至最后工作日+按劳动合同补偿 |
| 辞退（员工违规） | 结算至最后工作日，不额外补偿 |
| 严重违反规章制度解除 | 结算至最后出勤日，公司有权追究因违纪造成的损失 |

销售顾问和教练离职时，当月尚未结算的提成及课时费于次月发薪日随薪资一并发放。公司扣留不低于1,000元作为离职风险金，于离职后第60日发放。离职后60日内出现客户退费的，退费损失先从离职风险金中扣除，不足部分公司有权追偿。

### 3.4 入职资料

- 新员工入职须按公司标准模板填写简历，确保信息完整、真实、准确。
- 信息造假属于严重违纪，如有不实，公司有权单方面解除劳动合同，不支付任何经济补偿或赔偿金。

### 3.5 劳动关系声明

新员工入职时须签署《劳动关系声明》，确认以下事项：

- 已与原用人单位解除劳动关系，不存在任何未了结的劳动争议、仲裁或诉讼。
- 如有不实，视为违背诚信原则，公司有权无条件解除劳动合同，不支付任何经济补偿或赔偿金。

该声明作为劳动合同附件，与劳动合同具有同等法律效力。

## 四、薪酬体系

### 4.1 薪资发放

- **异议处理**：收到薪资3日内可提出异议

### 4.2 各岗位收入结构

| 岗位 | 收入结构 |
|------|----------|
| 教练 | 底薪（按星级）+ 课时费×出勤系数 + 业绩提成 |
| 顾问 | 底薪 + 业绩提成（3%-9%阶梯） |
| 店长 | 底薪 + 绩效1,000元/月 + 业绩提成 + 年度KPI奖金 |
| 教学主管 | 底薪3,000 + 岗位津贴1,000 + 绩效1,000/店 + 课时费 + 季度奖金 |
| 督导 | 基本工资4,000 + 绩效0-2,000 + 巡店补贴50元/次/店 |

### 4.3 教练薪酬要点

- 具体薪酬标准（底薪星级、课时费、提成比例、出勤系数等）按公司薪酬制度执行
- 2026年4月起，教练/顾问/店长取消月度绩效，改为每日工作量管理

### 4.4 薪资保密

薪资属于个人隐私，员工之间不得互相打听，店长不得公开他人薪资信息。违反者书面警告。

## 五、考勤制度

### 5.1 工作时间

| 项目 | 标准 |
|------|------|
| 排班制 | 店长根据课表安排班次，提前3天通知总部 |
| 月休 | 每月休息4天，由店长统一排休 |
| 打卡 | 每日上下班打卡（GYMGO系统/企业微信），须本人打卡，禁止代打卡 |

### 5.2 考勤规则

| 项目 | 标准 | 后果 |
|------|------|------|
| 迟到 | 超过规定到岗时间未到岗 | 迟到30分钟以内：当月取消全勤奖；迟到30分钟以上：按半天事假处理+当月取消全勤奖 |
| 早退 | 未到下班时间擅自离岗 | 早退30分钟以内：当月取消全勤奖；早退30分钟以上：按半天事假处理+当月取消全勤奖 |
| 周末请假 | 周末为排班工作日，原则不允许请假。确因特殊情况需请假的，须经店长批准，批准后仍按双倍时间扣减休假额度 | 当月取消全勤奖 |
| 旷工 | 未经批准不到岗超过半天 | 旷工1天扣3天工资，连续3天或累计5天→视为严重违反规章制度，公司有权解除劳动合同 |
| 代打卡 | 委托他人打卡或代他人打卡 | 双方当月取消全勤奖+书面警告 |
| 请假 | 提前24小时向店长书面申请 | 未提前申请按旷工处理 |

当月第1次迟到5分钟以内免于处罚；当月第2次起迟到取消全勤奖；当月第3次起迟到每次乐捐20元。早退、代打卡或周末请假的，全勤奖直接取消，不做按次扣减。全勤奖为底薪组成部分，当月满足全勤条件方可发放。

### 5.3 请假审批权限

| 请假时长 | 审批流程 |
|----------|----------|
| 半天以内 | 店长审批 |
| 1-2天 | 店长审核→总经理审批 |
| 3天及以上 | 总经理审批 |
| 病假 | 须提供医院诊断证明，1天以内店长审批，2天及以上总经理审批 |

### 5.4 全勤奖标准

| 岗位 | 全勤奖 |
|------|--------|
| 教练（实习/新星/一星） | 100-300元（按星级） |
| 教练（二星/三星） | 300元 |
| 顾问/教学主管/销售主管 | 200元 |
| 店长 | 300元 |

全勤奖为底薪组成部分，当月满足全勤条件方可发放，具体标准按公司专项制度执行。

### 5.5 调班换班

- 调班需提前1天向店长申请，店长审批后方可执行
- 调班后当周内自行补齐工作量
- 调班不影响全勤，但未按审批执行的按旷工处理

### 5.6 假期

| 假期类型 | 天数 | 说明 |
|----------|------|------|
| 法定节假日 | 按国家规定 | 排班调休 |
| 年假 | 满1年享5天 | 逐年递增，需提前1周申请 |
| 婚假 | 3天 | 需提前1个月申请 |
| 丧假 | 3天 | 直系亲属 |
| 病假 | 按国家规定 | 须提供医院诊断证明 |
| 产假/陪产假 | 按国家规定 | 需提前1个月申请 |

## 六、工作量管理

### 6.1 基本规则

- 每人每天完成4个工作量（从9类工作中任选）
- 教练和顾问统一标准
- 工作量与薪酬独立，不影响底薪/课时费/提成

### 6.2 工作量类别（9类）

| 类别 | 工作内容 | 工作量 |
|------|----------|--------|
| 教学 | 当日主课上传教案及课后点评 | 1 |
| 邀约到访 | 顾客邀约到访 | 1 |
| 成交 | 新签或续费课包 | 1-2（无上限） |
| 转介绍 | 获得转介绍客资 | 1 |
| 私域营销 | 每日3条朋友圈 | 1 |
| 获客 | 直播/地推销售小课包 | 1（无上限） |
| 线上运营 | 大众点评/抖音/美团好评 | 1 |
| 家校沟通 | 家长沟通3次 | 1 |
| 家校沟通 | 体测+运动规划 | 1 |

### 6.3 未达成处理

| 情形 | 处理方式 |
|------|----------|
| 1天未达成 | 次日补齐 |
| 连续2天未达成 | 乐捐进成长基金 |

| 连续5天未达成 | 公司安排一对一沟通谈话 |

具体乐捐标准按公司专项制度执行。

### 6.4 汇报要求

| 时间 | 要求 |
|------|------|
| 14:00前 | 门店群内提交工作量计划 |
| 22:00前 | 门店群内提交工作量总结复盘 |

## 八、行为规范

### 8.1 员工行为准则

1. 穿统一工服，佩戴工牌，保持专业形象
2. 上课期间严禁玩手机或做与教学无关的事
3. 不得体罚、冷暴力或言语侮辱学员
4. 不得私下收取家长费用或承诺优惠
5. 不得在家长群发布未经审核的内容
6. 不得与家长发生争吵或态度恶劣
7. 不得向家长传递与机构政策不符的信息
8. 严禁数据造假（出勤、课时、业绩等）

### 8.2 品牌一致性

员工对外发布品牌相关内容须使用公司统一素材和口径，不得自行编造。具体品牌执行标准按公司专项制度执行。

### 8.3 总红线（不可触碰，直接辞退）

- 体罚或冷暴力对待学员
- 数据造假（经查实二次）
- 发生重大安全事故且为主责方
- 私自收费或侵占公司财物
- 泄露公司核心商业信息
- 突发事件隐瞒不报

## 九、卫生与安全

### 9.1 日常要求

- 每日开课前和关店后各清洁一次教学区域
- 每节课后对教学器材进行酒精消毒并记录
- 每周三全员大扫除，同步进行安全排查
- 安全检查：器材螺丝松动、地垫破损、尖锐边角等

### 9.2 课堂安全底线

- 师生比：3岁以下≤1:4、3-6岁≤1:6、6岁以上≤1:8
- 每节课前须进行安全检查
- 发现安全隐患立即上报，不得隐瞒

## 十、突发事件应急处理

### 10.1 三级应急响应

| 级别 | 定义 | 处理要求 |
|------|------|----------|
| 绿色（一般） | 学员轻微擦伤、碰伤，无需就医 | 教练当场处理，记录，课后告知家长 |
| 黄色（较重） | 学员受伤需要就医、家长严重投诉 | 教练+店长处理，1小时内上报总经理，24小时回访 |
| 红色（严重） | 学员严重受伤、安全事故、媒体曝光 | 店长+总经理到场，立即启动应急预案 |

### 10.2 应急红线

- 突发事件隐瞒不报→立即辞退
- 未按应急流程处理导致事态扩大→书面警告+乐捐进成长基金

## 十一、培训与成长

### 11.1 新员工培训

所有新员工须完成试岗期培训（教练/顾问3天试岗+3天跟岗），考核通过后方可进入试用期。

### 11.2 教练星级晋升

教练职业发展路径：实习→新星（转正）→一星→二星→三星。

| 维度 | 新星（转正） | 一星 | 二星 | 三星 |
|------|-------------|------|------|------|
| 出勤要求 | 学员季度平均出勤率60% | 70% | 75% | 85% |
| 耗课量 | ≥50节 | ≥150节 | ≥300节 | ≥400节 |
| 续费业绩 | 无 | ≥1万/月 | ≥2万/月 | ≥3万/月 |

- 每年3次评定窗口（4月/9月/12月），首评9月
- 出勤系数连续2月<0.70→降级评估
- 保星制度：星级教练一年内须参加一次同星级以上考试

### 11.3 月度荣誉体系

根据公司安排评选个人之星（销售/续费/教学/服务/进步/明星老师）、团队荣誉（冠军团队/服务标杆店/进步最大店）和专项荣誉，获得者上形象墙、全员通报表扬。

## 十二、奖惩制度

### 12.1 奖励

公司设立荣誉体系等激励机制，具体按各专项制度执行。

### 12.2 违纪处理

员工违反公司制度的，公司根据情节轻重采取以下处理方式：

| 层级 | 情形 | 处理方式 |
|------|------|----------|
| 轻微 | 迟到、早退、未完成工作量、会议迟到等日常违纪 | 取消当月全勤奖、乐捐进成长基金、群内自罚红包 |
| 一般 | 工作量记录不真实、数据填报不规范、服务态度被投诉等 | 书面警告+乐捐进成长基金 |
| 严重 | 数据造假（首次）、未按应急流程处理、安全隐患隐瞒不报等 | 书面警告+乐捐进成长基金，情节严重辞退 |
| 极重 | 数据造假（二次）、体罚学员、私自收费、泄露商业信息、突发事件隐瞒不报等 | 立即辞退，追究法律责任 |

### 12.3 乐捐标准

对违纪情形公司可要求员工乐捐，乐捐金额进入成长基金奖金池。具体乐捐情形及金额按公司专项制度执行，公司有权根据运营情况调整乐捐标准，调整后经公示生效。

### 12.4 降级与降薪

- 教练出勤系数连续2月<0.70→降级评估
- 教学主管岗位津贴考核不达标→课时费降档
- 星级评定不达标→按评定结果调整底薪与课时费标准
- 具体降级标准及课时费降档规则按公司专项制度执行

### 12.5 制度申诉

对处理决定有异议的，按以下流程申诉：

1. 向店长提交书面申诉（3个工作日内）
2. 店长无法解决的，提交总经理裁定
3. 总经理裁定为最终决定，3个工作日内给答复

- 《追光小牛离职管理制度》

- 公司根据经营需要制定的其他规章制度

员工有义务主动阅读并知晓公司各项规章制度。公司通过企业微信群、公告栏、GYMGO系统等渠道发布制度修订通知，员工应及时查阅。以"不知情"为由违反制度的，不作为免责理由。

### 13.2 劳动纪律

员工须遵守以下劳动纪律，违反者按第十二章违纪处理：

1. 遵守工作时间，按时打卡，不得迟到、早退、旷工
2. 服从店长及上级的合理工作安排与调度
3. 不得同时在其他单位兼职
4. 不得利用职务便利谋取私利
5. 不得散布影响团队稳定的言论
6. 不得损坏公司财物，造成损坏须照价赔偿
7. 保守公司商业秘密，包括但不限于客户信息、薪酬数据、经营数据、管理制度

### 13.3 工时与加班确认

员工签署本手册即确认：

1. 公司因经营需要可安排加班，加班须经店长书面或企业微信审批，未经审批的自行延长工作时间不认定为加班
2. 加班补偿按国家规定执行，安排补休的在3个月内完成
3. 已知晓排班可能因季节、节假日等因素调整，服从公司排班安排

### 13.4 薪酬确认

员工签署本手册即确认：

1. 已知晓薪资核算依据为GYMGO系统数据+考勤记录
2. 已知晓底薪含全勤奖及交通补贴，出现迟到/早退/周末请假时全勤奖取消
3. 已同意出勤系数作为课时费计算系数，直接影响实际课时费收入
4. 已同意2026年4月起教练/顾问/店长取消月度绩效，改为工作量管理
5. 已知晓提成及课时费按月度实际发生核算，次月15日发放

### 13.5 工作量与绩效确认

员工签署本手册即确认：

1. 已知晓并同意每日完成4个工作量的管理要求
2. 已知晓未达成工作量的乐捐标准及处理方式
3. 已同意工作量与薪酬独立，不影响底薪/课时费/提成
4. 已同意工作量记录真实是基本诚信要求，虚假记录按数据造假处理

### 13.6 数据真实性与诚信确认

员工签署本手册即确认：

1. 已知晓所有经营数据（出勤、课时、业绩、工作量、考勤等）必须真实
2. 已知晓数据造假首次书面警告+乐捐进成长基金，二次辞退
3. 已同意公司有权通过GYMGO系统、监控、抽查等方式核验数据真实性
4. 已知晓虚假工作量记录、篡改截图日期、伪造沟通记录均按数据造假处理

### 13.7 保密义务

员工签署本手册即确认：

1. 在职期间及离职后均须保守公司商业秘密，包括但不限于客户信息、学员档案、薪酬数据、经营数据、教学方法、教案、管理制度、营销策略
2. 不得以任何方式将公司商业秘密泄露给第三方
3. 离职时须将所有公司资料、数据、账号归还公司，不得复制留存
4. 违反保密义务的，公司有权追究法律责任并要求赔偿损失

### 13.8 利益冲突与兼职禁止

员工签署本手册即确认：

1. 在职期间不得在其他同类型机构兼职或提供劳务
2. 不得利用公司客户资源、学员信息进行个人经营或为第三方谋利
3. 不得以个人名义收取家长费用或私下与公司客户发生交易
4. 不得在与公司有竞争关系的机构中持有股份或担任顾问
5. 存在利益冲突情形的，须主动向公司书面报备，未报备的视为违纪

### 13.9 培训服务期

公司为员工提供专项培训费用进行专业技术培训的，可签订《培训服务期协议》，约定服务期及违约金。员工在服务期内主动离职或因违纪被解除劳动合同的，须按比例退还培训费用。具体以《培训服务期协议》约定为准。

### 13.10 知识产权归属

员工在职期间因履行职务产生的所有成果，包括但不限于教学教案、课程体系、培训资料、营销方案、管理制度、客户资源等，知识产权均归公司所有。员工不得以个人名义主张权利或用于非公司业务用途。

### 13.11 工作设备与监控确认

员工签署本手册即确认：

1. 公司提供的工作手机、电脑、GYMGO账号等设备与系统归公司所有，员工仅有使用权
2. 公司有权对工作设备、系统账号中的数据进行检查和管理
3. 公司在门店安装监控设备用于安全管理和教学质量监督，员工知晓并同意
4. 不得利用公司设备从事与工作无关的活动，不得将公司设备转借他人

### 13.12 损害赔偿

因员工故意或重大过失造成公司损失的，公司有权要求员工赔偿：

1. 损坏公司设备、器材、设施的，按实际价值赔偿
2. 因教学事故导致家长退费的，退费损失由责任员工承担
3. 因数据造假导致公司决策失误的，承担相应损失
4. 因未按制度操作导致安全事故的，承担相应责任
5. 赔偿金额可从当月薪资中扣除，每月扣除金额不超过当月工资的20%，扣除后剩余工资不低于当地最低工资标准

### 13.13 离职确认

员工签署本手册即确认：

1. 已知晓离职须提前30天书面申请（试用期3天），未提前通知的公司有权要求赔偿损失
2. 已知晓连续旷工3天或累计旷工5天视为严重违反规章制度，公司有权解除劳动合同
3. 离职须完成全部交接，未完成交接的公司暂缓出具离职证明
4. 已同意销售顾问和教练岗位离职时公司扣留不低于1,000元离职风险金，于离职后第60日发放，期间出现客户退费的从风险金中扣除
5. 离职后须履行保密义务，违反的须向公司承担赔偿责任

### 13.14 送达确认

员工签署本手册即确认以下地址和方式为公司送达各类通知的有效途径：

1. 企业微信、微信、短信等电子方式发送至员工登记的号码
2. GYMGO系统站内消息
3. 员工入职登记的通讯地址
4. 上述任一方式发送即视为有效送达，员工联系方式变更的须3日内书面通知公司，未通知导致无法送达的由员工自行承担后果

### 13.15 公司权利保留

1. 公司有权根据经营需要调整员工岗位、工作内容及工作地点，调整后薪资按新岗位标准执行
2. 公司有权根据经营需要修订各项规章制度，修订后的制度经公示后对全体员工生效
3. 本手册未涵盖的事项，按公司其他专项制度执行；专项制度未涵盖的，按国家法律法规执行

### 13.16 安全与应急确认

员工签署本手册即确认：

1. 已知晓课堂安全底线及师生比标准
2. 已知晓突发事件必须按分级响应流程处理并上报
3. 已知晓突发事件隐瞒不报将被立即辞退
4. 已同意在岗期间履行安全管理职责，因个人疏忽导致安全事故的承担相应责任
