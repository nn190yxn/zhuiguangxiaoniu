## 一、制度（红线 + 规则 + 合同领取与保管）

### 1.1 红线

| 序号 | 红线内容 | 处罚 |
|------|----------|------|
| 1 | 不使用公司统一合同版本 | 乐捐100元 |
| 2 | 私自承诺优惠/赠送 | 乐捐100元 + 差额自补 |
| 3 | 退费不按统一标准执行 | 乐捐100元 + 差额自补 |
| 4 | 合同信息填写不完整/不真实 | 该单提成暂停发放 |
| 5 | 数据造假（虚报合同金额、伪造签名等） | 乐捐100元，二次辞退 |

### 1.2 规则

1. 所有合同必须使用公司统一版本，不允许自行修改
2. 合同填写必须完整、准确，不能有空项
3. 优惠活动须经总经理审批，不得私自承诺
4. 退费必须按统一标准执行，任何人不得擅自决定
5. 合同签订后当天录入GYMGO系统
6. 所有合同一式两份，按编号签订，一份交家长一份公司留存
7. 合同原件保持清晰可见字体，不得涂改

作废合同两联需返还财务。

### 1.3 合同领取与保管

| 环节 | 要求 |
|------|------|
| 合同申请 | 各门店根据需求，由门店负责人向财务部提出合同需求申请 |
| 合同盖章 | 所有合同由财务部盖章后提供，未盖章合同无效 |
| 合同签错处理 | 如合同签错、字迹不清晰等情况，不得损毁，须向财务申报该编号合同作废，作废合同两联返回公司财务 |
| 合同回收 | 合同原件每月由财务回收归档，合同照片存企业微信微盘 |
| 合同编号 | 按公司统一编号规则执行，不得跳号、重号 |

## 二、标准（做到什么程度）

### 2.1 合同填写规范

| 填写项 | 标准 | 说明 |
|--------|------|------|
| 单次训练单价 | 150元 | 统一单价，所有合同一致 |
| 会员管理费 | 训练总价 x 20% | 训练总价 = 课时数 x 单次训练单价 |
| 实际总金额 | 顾客实际支付金额 | 优惠后金额 |
| 购买课时数 | 按实际购买填写 | 课时卡填写课时数，周期卡填写周期 |
| 赠课节数 | 购买课时 + 赠送课时，填写总节数 | 须写清购买课程和赠送课程各自的节数 |
| 礼品名称及价值 | 如实填写 | 无礼品填"无"，不得留空 |
| 有效期（课时卡） | 购买课时数 x 5天 | 从首次上课日开始计算 |
| 有效期（周期卡） | 按购买时间签订有效周期 | 首次开卡时间最晚在购买后30天内，超期须申请延期 |
| 缺席次数（课时卡） | 购买课时数 / 3（取整数） | 超过缺席次数且未请假缺席，将扣除课时 |
| 缺席次数（周期卡） | 无请假缺席说明，过时即过期 | 周期卡不设缺席次数，过期作废 |
| 家长签名 | 必须本人签字 | 不接受代签 |
| 店长签名 | 必须签字 | 店长审核后方可生效 |

**合同金额计算示例：**

| 项目 | 计算 | 金额 |
|------|------|------|
| 购买课时 | 48节 | — |
| 赠送课时 | 2节 | — |
| 合同总节数 | 48 + 2 | 50节 |
| 单次训练单价 | — | 150元 |
| 训练总价 | 48 x 150 | 7,200元 |
| 会员管理费 | 7,200 x 20% | 1,440元 |
| 合同总金额 | 7,200 + 1,440 | 9,360元 |
| 实际支付（如打9折） | 9,360 x 0.9 | 8,424元 |
| 有效期 | 48 x 5 | 240天 |
| 缺席次数 | 48 / 3 | 16次 |

说明：赠课不计入训练总价和会员管理费计算，但计入合同总节数和有效期计算。

| 项目 | 标准 |
|------|------|
| 转卡条件 | 须在合同有效期内办理；过期课程不可转课；已上课时超过总课时50%的课包不能转让 |

### 2.4 退费标准

#### 1. 前三节课无理由退费（特殊通道）

| 项目 | 标准 |
|------|------|
| 适用条件 | 成交时承诺的前三节课内，家长无理由退费 |
| 退费金额 | 全额退还顾客实际支付总额，不扣除任何费用 |
| 课时处理 | 已上课程不计入课时费，视为体验课 |
| 责任划分 | 不做责任划分，不追责顾问和教练 |
| 办理流程 | 走退费审批流程（须有三轮书面沟通记录），但退费计算不走标准公式 |

说明：前三节课无理由退费是公司对客户的承诺福利。虽然不追责，但仍须完成三轮沟通挽留流程并留存书面记录。

#### 2. 标准退费计算（第四节课起）

| 项目 | 计算方式 |
|------|----------|
| 剩余退费金额 | 实际支付总额 - 已消费课程数 x 150元 - 手续费（20%） |
| 已消费课程单价 | 统一按150元/节计算，不按实际支付折后单价 |
| 手续费 | 实际支付总额 x 20%（以实际支付金额为基数） |

**退费计算示例：**

| 项目 | 计算 | 金额 |
|------|------|------|
| 实际支付总额 | — | 8,424元 |
| 购买课时 | — | 48节 |
| 已上课时 | — | 20节 |
| 已消费课程单价 | 统一原价 | 150元/节 |
| 已消费课程费用 | 20 x 150 | 3,000元 |
| 手续费（20%） | 8,424 x 20% | 1,684.8元 |
| 剩余退费金额 | 8,424 - 3,000 - 1,684.8 | 3,739.2元 |

#### 3. 退费责任划分

| 情形 | 责任人 | 处罚 |
|------|--------|------|
| 学员出勤率<70%且要求退费 | 主课教练 + 店长 | 教练扣300元 + 店长罚500元 |
| 因服务投诉导致退费 | 顾问 + 店长 | 顾问退回本单提成（含当月销售提点变化差额）+ 罚300元；店长退回总提 + 罚500元 |
| 合同信息填写不完整导致退费 | 顾问 + 店长 + 财务 | 顾问承担30%退费损失，店长承担50%退费损失，财务监管不力承担20% |
| 因教学质量问题退费 | 教练 + 店长 | 按实际情况追责 |
| 前三节课内无理由退费 | 不追责 | 不做责任划分，已上课程视为体验课 |

| 年卡 | 最多3期 | 总价 / 3 | 按月扣款 | 课程开始后60天内 | 课程开始后90天内 |

**分期审批要求：**

1. 分期须得到店长同意方可办理，未获批准的分期课程由销售人员垫付课程费用
2. 分期支付方案须在合同内明确后续分期费用的支付时间，并签约进合同
3. 合同内须注明违约条款："课程优惠建立在分期支付基础上，如未按期支付后续费用，课程费用按照原价计算课时或暂停课程使用"

> **注意：** 分期付款的学员退费时，只退已收金额，未收部分不再追缴。

## 三、流程SOP（怎么做）

### 3.1 合同签订流程

1. 顾问介绍课程和价格；家长确认购买
2. 如需分期，店长审批分期方案；审批通过后继续；未获批准的，销售人员垫付课程费用
3. 顾问填写合同（使用公司统一版本），检查填写是否完整（含赠课、礼品、有效期、缺席次数、停卡次数），检查金额计算是否正确
4. 如有分期，确认分期方案及违约条款已写入合同；确认家长签名
5. 店长审核签字；合格：收款 → 财务录入GYMGO（检查全部文件）→ 合同归档；不合格：退回修改 → 重新审核
6. 合同原件每月回收财务，照片存企业微信微盘中

### 3.2 退费流程

1. 家长提出退费要求，顾问记录退费原因
2. 第一轮：教练沟通，填写书面沟通记录表；挽留成功则继续上课
3. 第二轮：顾问沟通，填写书面沟通记录表；挽留成功则继续上课
4. 第三轮：店长沟通，填写书面沟通记录表；挽留成功则继续上课
5. 三轮挽留均失败后，顾问填写退费申请表（附三轮书面沟通记录）
6. 店长审核（检查合同、核实三轮沟通记录、计算退费金额）
7. 总经理审批（3天内完成）；审批同意后方可回复顾客退费结果
8. 财务执行退费（30个工作日内完成），在GYMGO更新学员状态，退费完成归档记录

关键节点：

- 三轮沟通记录必须为书面形式（微信截图/签字记录/沟通记录表均可），无记录不得提交退费申请
- 审批通过后方可回复顾客退费结果，不得在审批前向顾客承诺退费金额
- 前三节课无理由退费同样须走三轮沟通流程，但退费金额为全额，不走标准退费公式

### 3.3 停卡流程

1. 家长提出停卡申请，或顾问/教练发起停卡
2. 顾问检查停卡资格（次数/时长，区分课时卡或周期卡标准）
3. 符合条件：填写停卡申请单 → 家长签字 → 店长审批 → 财务在GYMGO操作停卡；不符合条件：向家长说明原因
4. 停卡开始，有效期顺延；停卡到期：GYMGO自动恢复 → 通知家长复课

### 3.4 转卡流程

1. 原会员提出转卡，顾问检查转卡条件（须在合同有效期内）
2. 符合条件：填写转卡申请单 → 原会员签字 + 新会员签字 + 店长签字（三方确认）
3. 财务在GYMGO操作转卡 → 新客户重新签订合同（合同金额为0元）→ 转卡完成
4. 不符合条件：向原会员说明原因

> **注意：** 如转卡未签订转卡申请表及新合同，扣罚200元。

### 3.5 特殊课卡处理流程

1. 顾问遇特殊课卡需求，向公司报备并获得同意
2. 按照各项合同标准签订纸质合同，提交合同至财务
3. 公司财务进行后台课卡录入，课卡激活后通知顾问和家长

原则：所有课卡以公司系统内课卡为准。特殊课卡须经公司同意后方可销售，不得自行创设课卡类型。

## 四、节点管理与跟踪考核

### 4.1 检查机制

| 检查项 | 谁检查 | 怎么查 | 频率 | 做不到怎么办 |
|--------|--------|--------|------|-------------|
| 合同完整性 | 财务 | 每月抽查合同台账 vs GYMGO | 每月 | 合同不完整 → 限期补全 |
| 合同金额准确性 | 财务 | 核对合同金额 vs 实际收款 | 每月 | 金额不一致 → 追查原因 |
| 退费合规性 | 财务 | 核对退费金额 + 三轮沟通记录 vs 退费标准 | 每笔退费 | 不合规 → 追回差额+追责 |
| GYMGO录入及时性 | 店长 | 检查合同签订日期 vs GYMGO录入日期 | 每周 | 未及时录入 → 顾问乐捐100元 |
| 分期还款跟踪 | 财务 | 检查还款记录 vs 分期截止时间 | 每月 | 逾期未还 → 顾问跟进 |
| 赠课/礼品登记合规性 | 财务 | 核对合同赠课/礼品栏 vs 实际赠送 | 每月 | 未登记 → 乐捐100元+差额自补 |
| 督导抽查 | 督导 | 合同台账 vs GYMGO vs 实际收款 | 每月1次 | 发现问题 → 限期整改 |

### 4.2 处罚细则

| 违规行为 | 责任人 | 处罚 |
|----------|--------|------|
| 不使用统一合同版本 | 顾问 | 乐捐100元 |

| 合同信息不完整 | 顾问 | 限期补全，逾期提成为0 |
| 合同未录入GYMGO | 顾问 | 限期补录，逾期提成为0 |
| 合同未签订标准有效期 | 顾问 | 本单提成为0 |
| 合同未签订标准缺席次数 | 顾问 | 本单提成为0 |
| 合同未签订标准停卡次数 | 顾问 | 本单提成为0 |
| 退费不按标准执行 | 责任人 | 乐捐100元 + 差额自补 |
