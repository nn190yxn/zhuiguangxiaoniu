# 追光小牛 · 考勤管理制度

| 项目 | 内容 |
|------|------|
| 版本 | v1.0 |
| 日期 | 2026年7月 |
| 适用范围 | 全部校区全体员工 |
| 主责 | 店长（执行）、督导（抽查） |

---

## 一、总则

### 1.1 目的

规范员工考勤管理，维护正常工作秩序，保障公司运营效率。

### 1.2 适用范围

本制度适用于追光小牛全体员工，含试用期员工。

### 1.3 工时制度

公司实行综合计算工时制，以月为计算周期。月休4天，由公司统一排休。

---

## 二、工作时间

### 2.1 排班

| 项目 | 标准 |
|------|------|
| 排班方式 | 店长根据课表安排班次，提前3天通知总部 |
| 月休 | 每月休息4天，由店长统一排休 |
| 打卡 | 每日上下班打卡（GYMGO系统/企业微信），须本人打卡，禁止代打卡 |

### 2.2 加班管理

- 公司因经营需要可安排加班，加班调休需走企业微信先申请，再调休
- 排班可能因季节、节假日等因素调整，员工须服从公司排班安排

---

## 三、考勤规则

### 3.1 迟到与早退

| 项目 | 标准 | 后果 |
|------|------|------|
| 迟到5分钟以内（每月1次） | 超过规定到岗时间5分钟以内 | 免于处罚 |
| 迟到（当月第2次起） | 当月第2次及以后迟到，不论时长 | 取消当月全勤奖 |
| 迟到（当月第3次起） | 当月第3次及以后迟到，不论时长 | 取消当月全勤奖+每次乐捐20元进成长基金 |
| 迟到30分钟以上 | 超过规定到岗时间30分钟以上未到岗 | 按半天事假处理+取消当月全勤奖 |
| 早退30分钟以内 | 未到下班时间擅自离岗 | 取消当月全勤奖 |
| 早退30分钟以上 | 未到下班时间擅自离岗30分钟以上 | 按半天事假处理+取消当月全勤奖 |

### 3.2 旷工

| 项目 | 标准 | 后果 |
|------|------|------|
| 旷工 | 未经批准不到岗超过半天 | 旷工1天扣3天工资 |
| 连续旷工 | 连续3天 | 视为严重违反规章制度，公司有权解除劳动合同 |
| 累计旷工 | 累计5天 | 视为严重违反规章制度，公司有权解除劳动合同 |

### 3.3 代打卡

委托他人打卡或代他人打卡的，双方当月取消全勤奖并给予书面警告。

### 3.4 全勤奖规则

当月第1次迟到5分钟以内免于处罚；当月第2次起迟到取消全勤奖；当月第3次起迟到每次乐捐20元。早退、代打卡或周末请假的，全勤奖直接取消，不做按次扣减。全勤奖为底薪组成部分，当月满足全勤条件方可发放。

全勤奖标准按公司薪酬制度执行。

## 四、请假管理

### 4.1 请假审批权限

| 请假时长 | 审批流程 |
|----------|----------|
| 半天以内 | 店长审批 |
| 1-2天 | 店长审核→总经理审批 |
| 3天及以上 | 总经理审批 |

### 4.2 请假规则

- 请假须提前24小时向店长书面申请（企业微信/GYMGO系统）
- 未提前申请且未到岗的，按旷工处理
- 请假期间不计发工资，按实际出勤天数核算

### 4.3 周末请假

- 周末为排班工作日，原则不允许请假
- 确因特殊情况需请假的，须经店长批准
- 批准后仍按双倍时间扣减休假额度（请1天扣2天）
- 月休4天额度用完后按事假处理
- 周末请假当月取消全勤奖

### 4.4 病假

- 须提供市级三甲医院以上病假条或诊断证明
- 1天以内店长审批，2天及以上总经理审批
- 病假工资按半天计算

### 4.5 调班换班

- 调班需提前1天向店长申请，店长审批后方可执行
- 调班后当周内自行补齐工作量
- 调班不影响全勤，每月调休一天班不影响全勤，但未按审批执行的按旷工处理

## 五、假期

| 假期类型 | 天数 | 说明 |
|----------|------|------|
| 法定节假日 | 按国家规定 | 排班调休 |
| 年假 | 满1年且转正享2天 | 入职满1年且转正2天，第2年3天，第3年4天，第4年5天，最多5天；每年过期作废，须提前1个月申请并安排好课程交接 |
| 婚假 | 3天 | 需提前1个月申请 |
| 丧假 | 3天 | 直系亲属 |
| 病假 | 按国家规定 | 须提供市级三甲医院以上病假条或诊断证明 |
| 产假/陪产假 | 按国家规定 | 需提前1个月申请 |

---

## 六、考勤核查

### 6.1 核查责任

| 角色 | 职责 |
|------|------|
| 店长 | 每日核查考勤，每月3日前提交考勤汇总 |
| 督导 | 每周抽查考勤记录 |
| 财务 | 根据考勤汇总核算薪资 |

### 6.2 异常处理

- 考勤异常须在发生后2个工作日内向店长说明原因
- 未说明原因的考勤异常按旷工处理
- 考勤记录以GYMGO系统/企业微信打卡数据为准

---

## 七、附则

1. 本制度自发布之日起施行，经公司公示后对全体员工生效
2. 公司有权根据运营情况修订本制度，修订后经公示生效
3. 本制度未涵盖的事项，按国家法律法规执行
