# 追光小牛教练薪酬制度

> **版本**：2026 年 H2 执行版 v2.0 | **适用范围**：全体教练（含实习教练）
> **生效日期**：2026 年 9 月 1 日 | **审批**：创始人、总经理

## 一、收入结构

教练月收入由三部分组成：

> 月收入 = 星级底薪 + 团课课时费 × 出勤系数 + 业绩提成

| 收入项 | 说明 | 关联依据 |
| --- | --- | --- |
| 底薪 | 按当前星级确定的固定底薪 | 星级 |
| 团课课时费 × 出勤系数 | 团课课时费按实际上课人数查表，乘以最终出勤系数 | 出勤人数、出勤系数 |
| 业绩提成 | 按个人月业绩区间核定 | 新签与续费业绩 |

## 二、星级底薪

| 星级 | 底薪（元/月） |
| --- | ---: |
| 实习 | 2100 |
| 新星 | 2500 |
| 一星 | 2500 |
| 二星 | 2700 |
| 三星 | 3000 |

2026 年 Q3 首评后，10 月起按新的星级发放底薪。星级评定规则见《教练星级评定制度》。

## 三、团课课时费

团课课时费按每节课的实际出勤人数核定。最终发放额为表内金额乘以当月最终出勤系数。

| 6 人 | 40 | 50 | 60 | 70 | 75 |
| 7 人 | 48 | 60 | 70 | 80 | 90 |

| 10 人 | 72 | 90 | 100 | 110 | 125 |
| 11 人 | 80 | 100 | 110 | 120 | 135 |
| 12 人 | 88 | 110 | 120 | 130 | 150 |

## 四、出勤系数

出勤系数由月耗课达成率和会员活跃度决定：先按主指标确定基础系数，再按活跃度做降档调整。

### 4.1 计算公式

- 月耗课达成率 = 当月标准课时人次 ÷ 月应出勤数 × 100%。
- 月应出勤数 = 教练名下会员数 × 5。
- 会员活跃度 = 当月有上课记录的去重会员数 ÷ 教练名下总会员数 × 100%。

| 月耗课达成率 | 基础系数 |
| --- | ---: |
| ≥100% | 1.10 |
| 80% 至 99% | 1.00 |
| 60% 至 79% | 0.85 |
| <60% | 0.70 |

| 会员活跃度 | 最终调整 |
| --- | --- |
| ≥80% | 保持基础系数 |
| 60% 至 79% | 降一档：1.10 至 1.00、1.00 至 0.85、0.85 至 0.70 |
| <60% | 最终系数为 0.70 |

### 4.2 核定口径

1. 标准课时人次按课程时长折算：1 小时班 ×1.0、1.5 小时班 ×1.5、2 小时班 ×2.0。
2. 固定课、自主约课和请假后的补课纳入计算；未签到的排课不纳入消耗。
3. 教练名下会员少于 10 人时，月耗课达成率正常计算，活跃度不作为要求。
4. 教练当月请假超过 5 个工作日时，当月出勤系数按 1.00 发放。
5. 跨校区教练按各校区课时占比计算加权平均系数。
6. 会员跨教练上课时，标准课时人次与活跃度归实际授课教练。
7. 虚报出勤数据时，当月出勤系数按 0.70 核定，并按红线制度处理。

### 4.3 月度核定流程

| 时间 | 责任人 | 动作 |
| --- | --- | --- |
| 每月 3 日前 | 店长 | 从 GYMGO 导出上月数据，计算达成率、活跃度和最终系数 |
| 每月 5 日前 | 教练 | 核对数据并签字确认 |
| 工资发放日 | 财务 | 按确认后的最终系数核算课时费 |

教练收到数据后 3 个工作日内可提出异议，逾期按确认处理。

## 五、业绩提成

个人月业绩按新签与续费合并计算，采用对应业绩档位的提成比例。

| 月业绩区间（元） | 提成比例 |
| --- | ---: |
| 0 至 5,000 | 2.0% |
| 5,001 至 15,000 | 2.5% |
| 15,001 至 25,000 | 3.0% |
| 25,001 至 35,000 | 3.5% |
| 35,001 至 45,000 | 4.0% |
| 45,001 至 55,000 | 4.5% |
| 55,001 至 65,000 | 5.0% |
| 65,001 至 75,000 | 5.5% |
| 75,001 至 85,000 | 6.0% |
| 85,001 以上 | 6.0% |

教练自签续费全额计入本人业绩；教练移交销售成交时，教练计入 10%，销售计入 90%。

## 六、月收入核算示例

| 教练姓名 | 星级底薪 | 团课课时费 | 最终出勤系数 | 业绩提成 | 月收入 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 填写 | 填写 | 填写 | 填写 | 填写 | 底薪 + 课时费 × 系数 + 提成 |

出勤系数同时作为季度星级评定的硬性门槛。星级、课时费、出勤系数和续费数据均按月度确认、季度汇总的方式留存。

## 七、附则

本制度经审批后生效。教练对数据或薪酬结果有异议时，可在公布后 3 个工作日内提出，由总经理裁决。
