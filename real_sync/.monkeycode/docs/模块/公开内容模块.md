# 公开内容模块

公开内容模块面向家长、搜索服务和 AI 检索，提供品牌、课程、门店、ACE 教学和家长决策内容。

## 结构

| 位置 | 职责 |
|------|------|
| `index.html` | 官网首页与精选内容入口 |
| `news/index.html` | 资讯专题和归档索引 |
| `news/*.html` | 独立公开文章 |
| `courses/` | 课程详情 |
| `stores/` | 贵阳 5 家门店详情 |
| `assets/public-insights.css` | 指南类文章共享样式 |
| `sitemap.xml` | 公开 URL 发现 |
| `robots.txt` | 搜索与 AI 爬虫规则 |

## 内容专题

- ACE：定义、课堂观察、评估解读。
- 品牌与家长指南：品牌优势、本地位置、选择清单、直营、课程、教练、安全、评估、试听和长期成长。

## 修改要求

新增文章需同步页面、资讯索引、必要的首页入口与 sitemap，并验证 JSON-LD、FAQ、内部链接、移动端布局和 HTTP 200。
