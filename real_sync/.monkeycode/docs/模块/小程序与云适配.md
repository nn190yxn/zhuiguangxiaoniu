# 小程序与云适配

该模块提供员工工作量、AI 演练、知识学习、个人中心等微信小程序能力，并支持直连与云代理迁移。

## 结构

- `mini-program/app.json`：页面、tabBar、插件和权限声明。
- `mini-program/pages/`：小程序页面。
- `mini-program/utils/api.js`：统一 API 客户端。
- `mini-program/utils/transports/`：direct、cloud、shadow transport。
- `mini-program/business-domain-matrix.json`：业务域与路由契约。
- `cloudfunctions/api-proxy/`：业务 API 白名单代理。
- `cloudfunctions/auth-proxy/`：认证白名单代理。
- `cloudfunctions/media-ticket/`：媒体票据云函数。
- `cloudrun/media-adapter/`：媒体适配服务。

## 请求路径

小程序 API 客户端根据 transport 策略选择直连 PHP API 或调用云函数。代理校验协议、路由、请求大小和幂等信息，并可使用 HMAC 签名访问上游。

设备会话刷新由统一客户端向 `/auth/mini-program-session.php?action=refresh` 发送 POST 请求，直连和云代理均传递 JSON 格式的刷新凭据与设备 ID。`mini-program/business-domain-matrix.json` 和 `cloudfunctions/api-proxy/business-domain-matrix.json` 在 `auth_session` 域登记同一 POST 路由，PHP 端点对其他业务方法返回 405。

业务矩阵中的 endpoint 以规范化的 method-path 作为唯一业务登记键。`home_todo` 域在源矩阵和部署矩阵中各保留一条 `GET /todos/my.php`，代理路由注册与小程序迁移清单保持一致。

`scripts/miniprogram_endpoint_contract.mjs` 提供 `normalizeEndpoint()`、`compareEndpointSets()` 和 `assertEndpointCollectionsEqual()`。规范化过程统一 method 大小写、保留 path，并按 query key/value 排序；比较结果提供左右差集和重复键，供矩阵同步门禁复用。

## 修改要求

新增路由应同步页面调用、业务域矩阵、云代理契约和测试。媒体接口还需核对大小、类型、校验和与恢复流程。
