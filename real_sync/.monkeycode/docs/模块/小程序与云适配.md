# 小程序与云适配

该模块提供员工工作量、AI 演练、知识学习、个人中心等微信小程序能力，并支持直连与云代理迁移。

## 结构

- `mini-program/app.json`：页面、tabBar、插件和权限声明。
- `mini-program/pages/`：小程序页面。
- `mini-program/utils/api.js`：统一 API 客户端。
- `mini-program/utils/transports/`：direct、cloud、shadow transport。
- `mini-program/business-domain-matrix.json`：业务域与路由契约。
- `cloudfunctions/api-proxy/`：业务 API 白名单代理。
- `cloudfunctions/auth-proxy/`：认证白名单代理。
- `cloudfunctions/media-ticket/`：媒体票据云函数。
- `cloudrun/media-adapter/`：媒体适配服务。

## 请求路径

小程序 API 客户端根据 transport 策略选择直连 PHP API 或调用云函数。代理校验协议、路由、请求大小和幂等信息，并可使用 HMAC 签名访问上游。

## 修改要求

新增路由应同步页面调用、业务域矩阵、云代理契约和测试。媒体接口还需核对大小、类型、校验和与恢复流程。
