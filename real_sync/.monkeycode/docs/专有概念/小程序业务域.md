# 小程序业务域

小程序业务域把页面、API 路由、认证要求、副作用、幂等要求、媒体字段和微信能力组织为可验证契约。

## 来源

`mini-program/business-domain-matrix.json` 是业务域和迁移路由的登记表。`cloudfunctions/api-proxy/index.js` 从矩阵生成允许转发的路由清单。

## 当前业务域

矩阵登记认证会话、运行能力、提醒订阅、首页待办、制度通知、学习、知识、考试、Drill v2、音频、工作量、凭证、管理、积分与档案等领域。

## 不变量

1. 云函数只转发矩阵登记的相对 API 路径。
2. 认证端点和业务端点分别由专用代理或业务代理处理。
3. 写请求按契约携带幂等键和副作用标识。
4. 小程序页面需覆盖 loading、empty、error 及对应写入状态。
